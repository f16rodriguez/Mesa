# Alpha 2: the corner

Approved user direction: playable real 3D scene with four seated characters, drink props and idle interactions, local phone UI just private tiles, ambient sound separate from user-supplied Suno music, and persistent profiles. Game of the Night includes actual spectators whose visible crowd grows, and communication to the table.

Retain existing pure rules and live-room transport. Presentation becomes a full-screen game, with simple title overlay and in-game lobby instead of website cards. One 3D nighttime Dominican corner: physical colmado shell, sidewalk, street, table, chairs, overhead lights, shelves, crates, bottles, small coffee and morir soñando. Fullbody realistic game meshes, seated rigs, visible breathing/gaze/arm movement. Generated reference assets are original characters, no competitor art is shipped.

STYLE FORMULA: Grounded cinematic game realism: believable Caribbean adults with natural proportions, detailed expressive faces, clean optimized forms and tactile linen, cotton, worn wood and glass materials. Environment palette deep turquoise, faded coral and warm brown; character clothing ivory, rust, indigo and ochre, skin varied warm natural tones. Warm affectionate proud neighborhood atmosphere, never caricature. Readable silhouettes and three-quarter reference perspective; neutral even asset lighting.

Budgets fixed before build: four seated 12k-triangle characters; viewer models capped at eight visible representations, additional viewers represented by true numerical count, never fake viewers. One shadow light, 1024 shadow map, maximum pixel ratio 1.5, target <150 draw calls and 60fps desktop; acceptable verified headless floor45fps. Light mobile controllers never load character scene assets. 28 live board tiles with hidden racks displaying opaque backs only, independent of camera angle. Performance quality tier disables distant decoration/shadows before reducing board legibility.

Character pass: ref -> textured rigged mesh -> Chair_Sit_Idle_M/F. Confirm skins and bones before integration; preserve original mesh animation. Procedural additive look/reach gesture over seated rig; actual tile placement scene interpolation synchronized to public server event. Drinking interaction asset alignment must be inspected; if not satisfactory, keep props grounded and report animation limitation rather than advertising finished sipping.

Accounts: D1 persistent profiles and server sessions as available first-party infrastructure; user can later migrate to Supabase. Username/password login optional, guest joining stays name-only. Country optional, age band optional and private; wins/losses server-owned. PBKDF2 salted password hashes, random session tokens hashed server-side, HttpOnly Secure SameSite cookies, authentication attempt throttle, profile values constrained, no public email/DOB. Series idempotency before stats updates. Completed hand history separate from series wins/losses. Bot-filled series marked casual not ranked.

Crowd: actual live spectator connections deduplicated by private credential and recent heartbeat, safe maximum32 connections, 8 visual crowd characters, spatially behind seated players. Public table chat with bounded message length/history, spam cooldown, spectators cannot play/reset/see private hands. Local per-speaker mute and whole-crowd mute saved by private sender pseudonym; host can mute abusive senders for room. Text bubbles/rail represent actual chat only. Voice and automated nightly selection remain distinct future work, not fake implementation. Game-of-the-night identity in this pass can be host-designated a featured live table, clearly not an automated global nightly winner.

First-pass acceptance: full hand from deal to result playable; four rendered seated humanoids; phones have no duplicated board or score UI in-hand; joining spectator increases actual count and scene crowd; text reaches table and mute works; sign-up/login/logout/profile persists; a verified completed series updates stats once; no private hands leaked in public views or meshes; new game opening does not leak old scene resources. Offline practice remains playable. Existing host-domain login barrier is documented, not bypassed.
